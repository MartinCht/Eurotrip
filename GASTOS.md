## ➕ Cómo agregar un nuevo consumo

Copiá la línea del resumen de tu tarjeta con este formato:

```
DD-Mmm-AA COMERCIO (PAIS,MONEDA, MONTO) CUPON MONTO
```

Ejemplo:
```
12-Sep-26 BOOKING.COM (NLD,USD, 250,00) 00812 250,00
```

Y pedile al agente: **"Agregá este consumo al tracker de gastos"**, indicando si es Traslado o Alojamiento (o el nombre de una nueva categoría si corresponde, por ejemplo Comida, Actividades, etc.).
